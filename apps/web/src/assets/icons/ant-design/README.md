# Ant Design scene icons

These eight SVGs are serialized from `@ant-design/icons-svg` version 4.5.0,
using the existing Ant Design icon dependency. Path data is unchanged; SVG
namespace and `fill="currentColor"` are added for CSS-mask rendering.

Source: <https://github.com/ant-design/ant-design-icons>
