# 画板创建与文字编辑

用这项 Skill 处理真实 Canvas Draft 的创建、读取、低风险文字修改和放置本会话已有图片结果。

## 使用条件

仅在用户明确要求使用画板，或继续此前明确要求的画板任务时使用。上下文中存在画板、上传了参考图，或提到设计、排版、修改图片，本身不构成使用画板的意图。不得为调用画板工具而自行增加可编辑画板交付物；其他能力不可用时也不得以画板替代原目标。

## 工作顺序

1. 如果用户明确要新建画板，先确认或从目标中得到画板名称和尺寸，再创建画板。不要用一段计划冒充画板。
2. 修改已有画板前必须先读取当前画板，使用读取结果中的最新版本、页面和元素事实。
3. 用户从 Canvas 携带了选区时，只能修改该选区中的元素；选区为空或目标不唯一时先询问，不猜测。
4. 每次文字修改必须带上刚读取到的版本。版本冲突后重新读取并重新判断目标，不得自行替换版本后重试。
5. 一次命令只组织同一用户意图下的少量文字新增或修改。完成后说明画板发生了什么，并提醒用户可在画板历史中恢复修改前版本。
6. 放置制作结果前，先读取本会话任务并确认具体图片；只能使用当前会话可见、可用且属于已关联制作任务的图片结果。多个结果不明确时先让用户选择。随后重新读取画板，并用最新版本、页面、位置和尺寸放置图片。

## 可直接进行的操作

- 创建空白画板；
- 读取画板名称、页面、尺寸和文字元素；
- 新增文字；
- 修改文字内容、字号和纯色文字颜色。
- 把本会话已有图片结果作为新的图片元素放到画板。

这些操作本身不产生图片模型费用，并且每次写入形成独立 Canvas Revision。生成新的图片、替换大范围内容、删除、发布和任何可能产生费用的动作不在本 Skill 内，必须使用运行时另行提供且符合确认策略的能力。

## 完成标准

- 只有领域命令真实成功后才能说“已创建”或“已修改”；
- 回复使用画板名称、页面和改动内容，不展示资源 ID、版本号、Tool 名称或内部错误；
- 发生权限、目标变化或版本冲突时，说明内容已有更新或当前无法修改，并给出重新查看或进入画板处理的下一步。
