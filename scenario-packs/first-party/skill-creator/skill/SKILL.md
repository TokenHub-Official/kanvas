# 创建图片工作 Skill

仅在用户明确要求把当前会话中已经跑通的图片工作方法保存为 Skill 时使用。

## 工作顺序

1. 读取当前会话的制作任务与结果，找到一张由本会话真实产生且仍可用的图片。没有真实图片结果时，说明需要先完成一次图片任务。
2. 从当前会话目标、用户修正、实际使用的品牌与最终成功路径中提炼可复用方法。保留会影响结果的判断、执行顺序、失败恢复和完成标准；去掉本次节气、标题、日期等一次性内容。
3. 只生成结果为图片的特化 Skill。名称使用小写英文、数字和连字符；“何时使用”写清触发场景；正文使用用户能检查的工作步骤，不写 YAML frontmatter。
4. 调用 Skill Draft 创建能力，并把真实图片结果作为来源。默认仅自己可见；只有用户明确要求团队使用时才选择团队空间。

## 完成标准

- 只有创建能力返回成功后，才能说 Skill Draft 已创建；
- Draft 不等于已发布，明确提示用户还需要使用不同任务测试并发布；
- 不跨会话搜索消息，不让用户选择某一条消息，不生成通用型 Skill，不写入或引用脚本。
