# 品牌社媒视觉制作

用这项 Skill 把“做一张品牌社媒视觉”推进到用户真正需要的结果，而不是停在单次 Tool 或 Workflow 成功。

## 先确定交付物

先判断本次交付是以下哪一种：

- **结果图**：用户只需要查看、下载或发布一张最终图片。
- **可编辑画板**：用户明确要求使用画板或在 Canvas 中继续工作；仅提到后续编辑或排版不足以确定画板意图。
- **两者都要**：用户明确要求一张可用结果图，同时保留可编辑画板。

只有用户明确要求继续此前已明确的画板任务时，才延续该任务的交付范围；不因上下文中存在或引用了画板就默认交付“两者都要”。只有不同选择会实质改变结果且上下文无法判断时，才追问一次；不要反复确认已明确的信息。

## 固定品牌约束

1. 用户选择品牌后，本会话后续步骤必须继续使用同一品牌 Revision，不能静默切换为默认品牌或其他版本。
2. 只能使用可信上下文中该品牌实际提供的 Logo、颜色和文字规范，不从名称、描述或历史结果猜测资源。
3. 如果用户请求的品牌主体与当前选中品牌明显冲突，例如要求万豪酒店海报却选中了 Kanvas 品牌，必须说明冲突并让用户选择更换品牌或继续使用当前品牌。
4. Logo 或品牌素材不可用、与预期明显不符时，不得将其当作正确素材继续制作；说明问题并给出重新选择或上传的恢复方式。

## 选择执行路径

1. 从请求与上下文确认主标题、受众、场景、比例和必要品牌素材。只追问会实质影响交付的问题。
2. “品牌底图合成”只会把一个 Logo 放到纯色方形底图中。只有用户明确要求“Logo + 纯色底图”时才能使用；用户要求海报、成品图、完整视觉或两者都要时，禁止用它代替图片生成。
3. 用户需要酒店、人物、产品、活动或生活方式主视觉时，先使用图片生成 Skill 形成匹配目标的图片结果。品牌颜色、调性和禁用项写入生成要求，Logo 按当前适用能力支持的方式处理；仅在用户已明确要求画板交付时，才留到画板排版阶段。
   - 如果当前没有可用的图片生成提案 Tool，立即说明图片制作能力尚未就绪，并引导有权限的用户检查模型与制作配置；不得先建空画板、改用品牌底图或用文字询问付费确认。
4. 需要可编辑画板或两者都要时，在图片结果真实可用后，通过任务卡上的“继续到画板”继续，然后使用画板 Skill：读取或创建目标画板、放置选定图片，再加入主标题与必要文字。每次写入都使用最新画板版本。
5. 本次包含用户明确要求的画板交付时，完成后重新读取画板，确认目标页面不为空、图片和主标题都已存在，并确认仍使用本次固定品牌。若检查失败，暴露当前未完成项和可恢复动作。

## 完成标准

- Workflow 提案已形成：只能说“待确认”。
- Workflow 已执行但 Artifact 尚不可用：只能说“制作中”或说明失败。
- 结果图交付：只有真实 Artifact 可读取后才能说“结果已准备”。
- 可编辑画板交付：只有图片和文字真实进入画板且复查通过后才能说“画板已完成”。
- 两者都要：必须同时满足结果图和画板标准；Workflow 成功本身不代表用户目标完成。
- Workflow 确认会结束当前回复。不得承诺结果生成后会自动续作；仅在用户已明确要求画板交付时，提示用户在结果准备后选择“继续到画板”。
- 回复使用作品、品牌、画板和下一步等业务语言，不展示内部标识、版本、模型、Provider、Tool 或技术错误。
